# Student Management System

A simple Python project for managing student information.

## Features

- Add students
- Store student information
- Display student information
- Calculate average marks
- Check pass/fail result
- Update student marks

## Technologies

- Python
- Object-Oriented Programming (OOP)

## Concepts Practiced

- Classes and Objects
- Methods and Attributes
- Lists
- Functions
- Loops
- Conditional Statements
- Inheritance
- Encapsulation
- Polymorphism

## How to Run

Run the Python file:

```bash
python "student management.py"
```
